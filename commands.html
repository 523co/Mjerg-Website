Commands

All 103 of them.

The default prefix is !, changeable per community. Anything marked with a red tag needs that permission. Mjerg reads it from your Osmium roles, there's no separate permission system to learn.

103 commands

ℹ️ Info

!about
Version, uptime, and who built Mjerg
!avatar [user]
Pull someone's avatar at full resolution
also !pfp
!communityinfo
Member count, channels, roles and creation date
!help [command]
List every command, or explain one in detail
also !commands  ·  e.g. !help warn
!members
Member count broken down by status and role
!ping
Round-trip latency to the Osmium gateway
!reach
How many people can actually see a message in this channel
!seen <user>
When a member last spoke
!stats
Mjerg's own numbers: communities, commands run, memory
!statschannel <members|online|off>Manage community
A channel that keeps a live count in its own name
e.g. !statschannel members
!uptime
How long the current process has been running
!userinfo [user]
Profile card: join date, roles, account age
also !whois
